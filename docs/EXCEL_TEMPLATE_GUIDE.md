# PCS Team — Power Query and Data Model setup

This setup is done once in desktop Excel. Afterward, daily use is only:

1. **Sync and refresh PCS Team** in WFMHub.
2. Open `Reports\PCS Team.xlsx`.
3. Choose **Data > Refresh All**.

No data is loaded to a worksheet. Power Query loads four small clean tables
directly into Excel's compressed Data Model.

## How the update works

```text
Untouched FTE + Call by Call extracts
              ↓
        WFMHub / SQLite
              ↓
  four files in _system\feeds\pcs\current
              ↓
        Excel Refresh All
              ↓
   PivotTables, slicers, and PCS charts
```

Adding a source extract alone does not change Excel. WFMHub must refresh first;
then Excel Refresh All reads the new feed.

Excel does not connect directly to SQLite. That would require an ODBC driver or
native connector that can be blocked by corporate application policy. The CSV
feed is portable, typed by the supplied queries, and easy to audit.

## The four tables

| Query | File | Grain |
|---|---|---|
| PCS Agent Day | `PCS_AgentDay.csv` | one agent/day |
| PCS Calls | `PCS_Calls.csv` | one low-score coaching opportunity |
| PCS Agents | `PCS_Agents.csv` | one agent |
| PCS Dates | `PCS_Dates.csv` | one calendar date |

Summary and trend files are not needed. PivotTables calculate them from the
agent/day fact table. `PCS Dates` is generated by Python and contains only the
required calendar range, so it refreshes quickly.

## Open the protected workbook

Open `Reports\PCS Team.xlsx`. Keep it in `Reports` so the whole team follows the
same operating convention. Its `SETUP` sheet shows the expected feed location.

WFMHub does not overwrite this workbook during normal operation. If it is
deleted, use **System and advanced tools > Create PCS Team workbook if missing**.

## Add each Power Query

`SETUP.cmd` generates installation-specific scripts under
`_system\power_query`. Each one contains the literal local feed path, so Power
Query sees only one file data source and does not need to combine
`Excel.CurrentWorkbook` with `File.Contents`.

Do the following for `_system\power_query\PCS_AgentDay.pq`:

1. In Excel choose **Data > Get Data > From Other Sources > Blank Query**.
2. In Power Query choose **Home > Advanced Editor**.
3. Delete the text already there.
4. Open `_system\power_query\PCS_AgentDay.pq` in Notepad.
5. Copy all its text into Advanced Editor and choose **Done**.
6. Rename the query exactly `PCS Agent Day`.
7. Choose **Home > Close & Load > Close & Load To...**.
8. Select **Only Create Connection**.
9. Tick **Add this data to the Data Model**.
10. Choose **OK**.

Repeat with:

| Script | Exact query name |
|---|---|
| `PCS_Calls.pq` | `PCS Calls` |
| `PCS_Agents.pq` | `PCS Agents` |
| `PCS_Dates.pq` | `PCS Dates` |

Each query reads one file directly. No query references another query, which
avoids the Power Query privacy/firewall error encountered by the previous
design.

If the complete WFMHub folder is moved later, run `SETUP.cmd` again and replace
the four queries with the newly generated scripts.

## Create the four relationships

In Excel choose **Power Pivot > Manage > Diagram View**. Create only these:

```text
PCS Agents[agent_id]  1 ─── *  PCS Agent Day[agent_id]
PCS Agents[agent_id]  1 ─── *  PCS Calls[agent_id]

PCS Dates[date]       1 ─── *  PCS Agent Day[business_date]
PCS Dates[date]       1 ─── *  PCS Calls[business_date]
```

The arrow starts from the dimension containing one unique row and points to the
fact containing many rows. Do not accept any additional relationship suggested
by Excel.

## Create the PCS measures

Choose **Power Pivot > Measures > New Measure**. Set **Table name** to
`PCS Agent Day`, then add:

```text
PCS Average :=
DIVIDE(
    SUM('PCS Agent Day'[q1_score_sum]),
    SUM('PCS Agent Day'[valid_q1])
)

PCS Participation :=
DIVIDE(
    SUM('PCS Agent Day'[q1_nonblank]),
    SUM('PCS Agent Day'[pcs_status_1])
)

Low Score % :=
DIVIDE(
    SUM('PCS Agent Day'[score_le_3]),
    SUM('PCS Agent Day'[valid_q1])
)

Positive % :=
DIVIDE(
    SUM('PCS Agent Day'[score_gt_3]),
    SUM('PCS Agent Day'[valid_q1])
)
```

Format PCS Average as `0.00`. Format the other three as `0.0%`.

For coaching, set Table name to `PCS Calls` and add:

```text
Coaching Opportunities := COUNTROWS('PCS Calls')

Coaching Completed :=
CALCULATE(
    COUNTROWS('PCS Calls'),
    'PCS Calls'[coaching_status] = "Completed"
)

Actions Rate := DIVIDE([Coaching Completed], [Coaching Opportunities])
```

Format Actions Rate as `0.0%`.

Do not put `q1_score_sum` in Values and present it as PCS. The score is the sum
divided by `valid_q1`; use the PCS Average measure.

## Create the main PivotTable

1. Choose **Insert > PivotTable > From Data Model**.
2. Put it on `PIVOT_AREA`.
3. Add Rows from `PCS Agents`: LOB, Team Leader, Agent Name.
4. Add Values: PCS Average, PCS Participation, valid Q1, score <= 3.
5. Add a Timeline using `PCS Dates[date]`.
6. Add slicers using `PCS Agents[LOB]`, Team Leader, and Agent Name.
7. Use **PivotTable Analyze > Report Connections** to connect the slicers to
   the desired model PivotTables.

Build a separate PCS Calls PivotTable for coaching opportunities. Because both
facts use the same Agent and Date dimensions, dimension slicers can control
both.

## Coaching workflow

The business rule is:

```text
Actions Rate = completed coaching / valid inbound Q1 responses <= 3
```

The persistent `COACHING_LOG` sheet is the only manual input area.

1. Filter `PCS Calls` to the opportunity you handled.
2. Copy its `coaching_key` into `COACHING_LOG`.
3. Select Pending, Completed, or Not required.
4. Enter the coaching date, coach, and comment.
5. Save `PCS Team.xlsx`.
6. Next time, choose **Sync and refresh PCS Team** in WFMHub.

WFMHub validates the key against eligible low-score calls, imports the decision
into SQLite, republishes `PCS Calls`, and preserves the workbook.

## If it does not refresh

- **SUM error:** replace the query with the supplied `.pq`; it explicitly types
  count and score fields as numbers.
- **File not found:** confirm `PCS Team.xlsx` is directly inside `Reports`, then
  check the feed path on `SETUP`.
- **No new date:** run WFMHub **Sync and refresh PCS Team** before Excel Refresh
  All.
- **Relationship error:** check that Agent IDs are text in both facts and that
  the relationship begins at `PCS Agents`.
- **Date relationship error:** use `PCS Dates[date]`, not a text Month label.
- **Slicer controls only one PivotTable:** use Report Connections and make sure
  the slicer field comes from `PCS Agents` or `PCS Dates`.
- **Refresh is slow:** confirm all four queries are Connection Only and none is
  loaded to a worksheet.

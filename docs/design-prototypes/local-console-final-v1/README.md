# WFMHub Manager Workbench — final prototype

This is a clickable, data-static design prototype for the five console views
that already have governed application contracts:

1. Daily Control
2. Staff Preparation
3. Intraday Service
4. Attendance & Schedule Review
5. Historical Review

Open `index.html` locally and use the cycle navigator. The LOB selector is a
working multi-select demonstration and filters visible LOB evidence. All values
are illustrative; no source extract, calculation, production page or database
is changed by this prototype.

The design deliberately avoids decorative dashboards. It uses a contiguous KPI
ledger, table-first evidence, page-specific working views, restrained status
colour, exact data-cut labels and explicit service/capacity grain boundaries.

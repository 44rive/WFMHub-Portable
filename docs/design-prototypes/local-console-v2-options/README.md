# Local Console V2 — design options

These are illustrative visual choices, not implemented application pages.
Business values are dummy examples. All three options preserve the governed
service, capacity, attendance, PTO/Away and final Activities boundaries.

## Review images

- [Full Workforce Manager application map](application-map.png)
- [Option A — Manager Command Center](option-a-command-center.png)
- [Option B — Manager Exception Desk](option-b-exception-desk.png)
- [Option C — Manager Cycle Cockpit](option-c-cycle-cockpit.png)

- **Option A — Manager Command Center:** recommended. Best balance across live
  RTM, forward staffing, schedule integrity, final absence and a single ranked
  WFM-cycle action queue. It makes RTM Daily Control native while retaining an
  Excel handoff button.
- **Option B — Manager Exception Desk:** strongest for treating one operational
  or planning case at a time. It spans live, next-28-day and post-day exceptions,
  trading some broad visibility for a queue/detail/playbook workflow.
- **Option C — Manager Cycle Cockpit:** strongest horizon view across Now, next
  four hours, tomorrow, current week and current month. It is visually
  distinctive but takes more operator learning than Option A.

Every design uses true multi-select filter chips, saved views, a clear-data
action, independent source cutoffs, and no synthetic all-LOB service KPI.

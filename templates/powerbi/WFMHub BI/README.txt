WFMHUB BI
=========

Open WFMHub BI.pbip with Microsoft Power BI Desktop, then choose Home > Refresh.
The HubRoot parameter is set automatically when this project is opened through POWERBI.cmd.
The model reads only Feed\PowerBI CSVs and never reads SQLite or raw extracts.
The five pages follow the WFM cycle: today's control, staff preparation, intraday service, schedule review and historical review.
All visuals are native Power BI visuals; no marketplace visual is required.
PCS remains a separate collaborative Excel product and is not imported into this WFM-only model.

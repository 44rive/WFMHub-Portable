WFMHub publishes every current report in this folder using a fixed name.
All workbooks are generated directly by Python and SQLite. Before WFMHub
replaces one, the previous copy is saved under Reports\Archive\YYYY-MM-DD.

Attendance Callout.xlsx   Who must be contacted now
Staffing Gaps.xlsx        Capacity gaps by LOB/language/interval
OEM Flash.xlsx            Ford OEM service and forecast control
Attendance Review.xlsx    Completed-day gaps awaiting Verint correction
Final Absenteeism.xlsx    Corrected Verint absence/shrinkage ledger
Bonus Management.xlsx     Bonus Matrix v1.2 decision workbook
PCS Performance.xlsx      PCS, participation, trends and coaching

PCS Performance.xlsx contains its own selector-driven dashboard, Excel Tables,
and editable coaching columns. It has no Power Query or Data Model connection.
